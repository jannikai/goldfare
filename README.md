# GoldFare

Interactive concept prototype for a precious-metals comparison platform.

## Concept

GoldFare helps customers compare the total price to buy—or the best estimated offer to sell—standardized gold and silver products through verified online and local dealers.

## Prototype features

- Buy and sell comparison modes
- Gold and silver product selection
- Transparent premiums, shipping, pickup, and estimated totals
- Local NYC dealer flow
- Reservation and appraisal-request interactions
- Dealer-network and price-alert forms
- Responsive static interface

All displayed market prices and dealer offers are demonstration data, not live quotes.

## Run locally

```bash
python3 -m http.server 8765
```

Then open `http://127.0.0.1:8765`.
